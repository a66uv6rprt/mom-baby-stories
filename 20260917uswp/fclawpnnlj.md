# 不痛的宫腔镜检查— —“阴道内镜”

> 更新时间：2026-09-17 (UTC+8)

近日，通过阴道内镜检查的治疗手段，我们顺利为一位特殊患者消除了病痛。

患者是一位20岁的青年女性，先前因不规则阴道流血曾去多家医院就诊，超声检查怀疑子宫内膜息肉。但因为无性生活史，不能进行手术治疗。而药物治疗又无效，患者非常苦恼，因此便来到我院妇科门诊就诊。了解病情后，妇科门诊医生建议她做阴道内镜检查，查证到底是息肉还是其他情况。一听说要手术，姑娘十分紧张和害怕，尤其担心自己还无性生活史，怕因为手术而破坏了处女膜。为打消患者的疑虑，接诊医生向患者及她的家属详细介绍了阴道内镜适应症和检查过程，明确告知她此项检查不会破坏处女膜的完整性。最终，患者于我院门诊手术室完成了阴道内镜检查，确诊为子宫内膜息肉并进行了成功的治疗。

**什么是“阴道内镜检查”呢？**

“阴道内镜检查”，有人称之为“门诊宫腔镜”，是用纤细的宫腔镜（直径4.5-5.mm）进行的宫腔镜检查，能直接看见阴道、子宫腔内情况，对大多数阴道及子宫腔内疾病可迅速作出精确的诊断。几乎所有宫腔内疾病的诊断“金标准”都是阴道内镜检查。例如：

1.异常子宫出血：生育期、围绝经期及绝经后出现的异常出血，月经过多经期长，不规则流血，是宫腔镜检查的主要适应症。

2.异常宫腔内声像学所见，宫腔镜检查可以对宫腔内病变进行确认、定位、对可疑之处还可定位活检进行组织细胞学检查，观察子宫内膜的发育情况，是否存在内膜增生或内膜息肉。

3.不育症（不孕、习惯性流产）观察宫腔及输卵管开口的解剖学形态，是否存在子宫畸形、宫壁粘连、粘膜肌瘤等，行输卵管开口插管通液或输卵管导丝疏通。

4.检查宫内节育器，观察其位置是否正常、嵌顿、断裂、残留。

5.宫腔粘连的诊断及分型。

6.检查幼女阴道异物。

7.宫腔镜手术后的疗效观察（术后二探）。总之，对疑有任何形式的宫腔内病变或需要对宫腔内病变做出诊断及治疗者，均可行阴道内镜检查。

**阴道内镜检查与传统宫腔镜相比有哪些优势？**

1.无需阴道窥器，无需扩张宫颈口，无明显疼痛，无需麻醉（如果患者极度恐惧，也可应用麻醉），减少了患者的不适与痛苦。

2.不破坏处女膜的完整性，尤其适合未婚女性，可对幼女或未婚妇女进行检查。

3.宫颈的侵入性更少，减少迷走神经兴奋综合症等并发症发生。

4. 在门诊即可完成，做完检查在医院短暂休息后即可回家，无需住院，减少了患者的经济负担，为患者节省了时间。

“阴道内镜”的开展实现了宫腔镜检查从微创到无创的转变，技术实用，是微创诊诊疗领域中的新方法、新技术。
